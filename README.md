# Tip Calculator App

## Project Overview

The **Tip Calculator App** is a simple web application that allows users to calculate the tip amount based on the total bill and the percentage of tip they want to leave. The app also calculates the total amount per person, considering the number of people splitting the bill. It provides a clean and interactive design with custom tip percentage input, multiple preset tip percentage buttons, and a reset button to start over.

## Technologies Used

### 1. **HTML**
   - The structure of the application is built using **HTML5** to define the layout, including input fields for the bill amount, number of people, and tip percentage, as well as output areas for the calculated tip amount and total per person.

### 2. **CSS**
   - **Custom Styles**: The app's styling is done using **CSS**, where we have custom styling for input fields, buttons, and overall layout.
   - **Responsive Design**: The app is responsive and uses **media queries** to adjust its layout for mobile and desktop views.
   - **Fonts**: The app uses **Space Mono** from **Google Fonts** to give it a modern, clean look.
   - **Button Hover Effects**: Interactive buttons with hover effects improve user experience.

### 3. **JavaScript**
   - The app uses **JavaScript** to handle user interactions, calculate the tip, and update the displayed results dynamically. It also resets the form when required.

## What I Made

1. **HTML Structure**:
   - The HTML layout includes:
     - **Bill Input**: Allows the user to enter the total bill amount.
     - **Tip Buttons**: Buttons for preset tip percentages (5%, 10%, 15%, 25%, 50%) and a custom tip input field.
     - **Number of People Input**: A field for entering the number of people sharing the bill.
     - **Calculated Results**: Displays the tip amount and total per person.
     - **Reset Button**: A button to reset the values and start fresh.

2. **Responsive Layout**:
   - The app is designed to be responsive with a mobile-first approach. It adjusts dynamically based on the screen size using media queries to provide an optimal experience across devices.
   
3. **Styling**:
   - Custom CSS styles are applied for the overall look of the application, including the layout, colors, typography, and button designs.
   - **Hover effects** are added for interactive buttons to enhance the user experience.

4. **JavaScript Interactivity**:
   - The **JavaScript** code listens for user input on the bill amount, the number of people, and the tip percentage, then updates the displayed results dynamically.
   - The reset button clears all input fields and calculations, providing a fresh start.

## Key Features

1. **Interactive Tip Calculation**: Users can select a preset tip percentage or enter a custom value, and the app will calculate the tip per person and total per person.
2. **Responsive Design**: The app looks great on all devices, adjusting the layout for mobile and desktop screens.
3. **Custom Tip Percentage**: Allows users to enter their own custom tip percentage.
4. **Reset Button**: Easily reset the form with the click of a button to start a new calculation.
5. **User Feedback**: The app provides real-time feedback on the calculated results as users enter data.

## Conclusion

The **Tip Calculator App** provides an easy-to-use interface for calculating tips and splitting bills. Built with **HTML**, **CSS**, and **JavaScript**, it offers dynamic calculations based on user input. With its responsive design, the app is optimized for all screen sizes, ensuring a seamless experience for users on mobile, tablet, or desktop devices.
